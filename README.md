🌌 What It Is

Reality Engine is an interactive ergodic feedback simulator — a living dashboard that lets users tune the fundamental parameters of consciousness, coherence, and reset dynamics.
It bridges neuroscience models, systems theory, and metaphysical exploration into a single visual framework.
